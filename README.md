# Diabetes Prediction Using Machine Learning

## Project Description
This project predicts whether a person may have diabetes using a Machine Learning classification model. It uses patient health details such as glucose level, blood pressure, BMI, age, and other medical attributes to generate a prediction.

The model is built using **Python and Logistic Regression**, with Pandas for data handling and Matplotlib for visualization.

## Technologies Used
- **Python** – Programming language
- **Pandas** – Data manipulation and analysis
- **NumPy** – Numerical computing
- **Matplotlib** – Data visualization
- **Scikit-learn** – Model training, testing, and evaluation
- **Logistic Regression** – Classification algorithm
- **Jupyter Notebook** – Development environment

## Features
- Creates and processes a diabetes-related dataset.
- Splits data into training and testing sets.
- Trains a Logistic Regression classification model.
- Evaluates model accuracy.
- Accepts patient details as user input.
- Predicts a diabetes class based on the trained model.
- Displays a bar chart of the dataset's outcome distribution.

## Project Files
- `Diabetes_Prediction_ML.ipynb` – Diabetes prediction code, model training, and visualization.
- `python with data science.ipynb` – Python and Data Science practice.
- `python with data science2.ipynb` – Additional practice notebook.

## How to Run
1. Clone or download this repository.
2. Install the required libraries:

   ```bash
   pip install pandas numpy matplotlib scikit-learn
   ```

3. Open `Diabetes_Prediction_ML.ipynb` in Jupyter Notebook or JupyterLab.
4. Run the notebook cells in order.
5. Enter the requested patient details to view the model prediction.
